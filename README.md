## Things I've built

- [Plan Graph](https://github.com/FenixSC2/plan-graph) is an agent skill that shows you every screen, command and endpoint your AI coding agent is about to build, plus every assumption it would have made without asking. You edit the graph in a local editor, and the agent builds from your changes. TypeScript and React Flow.
- [CanvAssist](https://canvassist.com) is a calmer dashboard for Canvas LMS, with workload estimates for the week, grade what-ifs and every deadline in one place. It's live, and there's a demo you can try without an account. FastAPI, React and Postgres on AWS. [Code](https://github.com/FenixSC2/canvassist)
- [Headcount](https://apps.apple.com/us/app/headcount-group-pings/id6799583840) is a group ping app on the iOS App Store. One tap notifies everyone in the group, and streaks show how often you all check in. React Native (Expo) and Supabase.
